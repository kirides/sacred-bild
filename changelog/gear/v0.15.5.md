## v0.15.5 (2026-11-27)

- Improved: mod windows open and update faster with a theme mod that has a big sprite sheet. The theme's picture styles (`.sprite-N`) are now loaded only into windows that use them, so every other window carries a fraction of the style rules it did before.
- New: a theme mod can name its sprite sheet in `mod.lua` (`theme_sprites`, `theme_sprites_dp` for pixel-sized windows). A window gets it when its markup uses a `sprite-` class, or when it is loaded with `sprites = true` (`sprites = false` never loads it).
- Under the hood: the UI sandbox has a deterministic test clock, so animations and the text caret can be tested frame by frame, and a new test covers the sprite sheet loading.
